## 機能

- **収支入力**: 入金・出金・チャージの3種別。明細は複数行（単価・値引き・数量から実額を自動計算）
- **一覧**: 月ごとの記録一覧と日別小計、月切り替え
- **明細検索**: 全明細の横断キーワード検索
- **統計**: 月次の収支サマリーと費用区分別の内訳グラフ（Recharts）
- **残高**: 現金・IKOCCA の残高を全記録から算出
- **クレジット管理**: 引落年月ごとのカード別使用額と処理ステータス管理
  （購入日に応じた引落年月のデフォルト計算: 翌月 / 16日以降は翌々月）
- **PWA対応**: ホーム画面に追加してネイティブアプリ風に利用可能

## 本番版とデモ版のアーキテクチャ

このリポジトリは、実際に家庭で運用している本番版から個人情報・実データを除いて公開用に変換したものです。

| | 本番版（私用・非公開） | デモ版（このリポジトリ） |
| --- | --- | --- |
| データストア | Google スプレッドシート（Sheets API v4 を素の `fetch` で呼び出し） | インメモリストア + 決定的シード生成（`lib/store.ts` / `lib/seed.ts`） |
| 認証 | Google OAuth + メール許可リスト + トークン自動リフレッシュ | ゲストログイン（Credentials プロバイダ） |
| デプロイ | Cloudflare Workers（`@opennextjs/cloudflare`） | Vercel |

データアクセスは `lib/sheets.ts`（本番）/ `lib/store.ts`（デモ）が提供する **同名・同シグネチャの8つのドメインAPI** に集約してあり、呼び出し側（`lib/data.ts` の集計ロジック・`lib/actions.ts` の Server Action）は一切変更せずにストアを差し替えられました。データ層をドメインAPIの背後に隠しておいたことで、この変換の差分が小さく済んでいます。

デモのサンプルデータは月キーをシードにした乱数（mulberry32）で生成するため、同じ月はいつ起動しても同じデータになります（現在月を末尾とする4ヶ月分）。
